# 董公選擇日要覽 — 判詞邏輯整理(B 階段規格)

目的:把 `divination/donggong_data.py`(原典 141 條,公有古籍)的判詞邏輯拆解成
可計算規則,作為「逐干支貼近唯心」(B)的實作規格。**本文件只整理邏輯,不改系統。**
最終吉凶以唯心電視/元壎法師為準;用詞由我們自寫(原典/規則為公有)。

---

## 1. 判詞模型

每日判詞 = **f(月建, 日支, 日干)**,三層疊加:

```
吉凶 = 建除位置基準(月建+日支)
       ⊕ 神煞疊加(多數可由 月→日支 或 干支 公式算)
       ⊕ 天干特例覆蓋(正四廢/煞集中宮/天月德/黃羅紫檀…依「日干支」)
```

優先序(高→低,暫定,B 階段以唯心樣本校準):
1. **大凶煞**:煞集中宮、正四廢、月破+凶煞、小紅沙+朱雀勾絞 → 大凶/百事不宜
2. **大吉神**:天赦、月德、天德、黃羅紫檀+諸吉(成日天喜) → 大吉
3. **凶煞**:朱雀勾絞、往亡、天賊、到州、九土鬼、受死 → 凶
4. **小吉**:次吉(黃羅紫檀單見、火星、有氣之干支)、除日 → 小吉
5. 否則 → 建除基準(平/小吉/凶)

## 5. 天干特例機制(原典每條內含)

同一「月+日支」下,不同**日干**判詞不同。原典以散文標出,例:
- 「**庚申、辛酉**正四廢,更凶」/「**壬子、癸亥**」… → 正四廢覆蓋為大凶
- 「**甲辰、戊辰**煞集中宮,百事皆忌,大凶」/「丙戌戊戌庚戌壬戌煞集中宮」… → 大凶
- 「**丁酉**有天德福星…宜安葬…餘酉日不可用」 → 天德干支轉吉
- 「**戊子丙子庚子**三日…用之大吉」/「甲子自死之金…不宜」 → 干支分吉凶
- 「**庚辰**天月二德…次吉」 → 天月德干支轉次吉

**B 實作法**:把這些「干支特例」從原典逐條解析成表 `干支特例[月][日干支] = (吉凶, 註)`,
疊在 §3 建除基準之上。這是 B 最重工、最易錯的部分(~720 格,須對唯心校驗)。

## 6. 建議實作架構(B)

```
日 → 月建/日支/日干
  1) 建除基準(§3 表)          → base level/text
  2) 神煞計算(§4 可算者)       → 覆蓋/疊加(往亡/正四廢/紅沙/天德/天赦/月德…)
  3) 干支特例(§5 解析原典表)    → 最高優先覆蓋(正四廢/煞集中宮/天月德…)
  4) 三煞/正沖(§2)            → 附註
  → 輸出吉凶等級 + 中性宜忌
驗證:唯心 16+ 天樣本逐日對吉凶方向;差異以唯心為準,回頭調規則。
```

逐步上線順序:§4 可算神煞(立即提升準度)→ §5 干支特例表(分月補,先補高頻:正四廢/煞集中宮/天月德)。
