## B. 空亡（旬空）— 真空假空

### B1. 旬空起例
- **條件**：輸入日干支 → 該旬所空二支（甲子旬戌亥、甲寅旬子丑、甲辰旬寅卯、甲午旬辰巳、甲申旬午未、甲戌旬申酉）；卦中逢此二支之爻=旬空。純干支可算。
- **依據**：卜筮正宗·旬空起例。
- **引擎**：**已有**（題述「已算旬空」；需確認以日干支六十甲子計算）。

### B2. 真空 vs 假空判別
- **條件（不為空＝假空，仍有用，待出空填實）**：旺相｜發動｜動而化空｜伏而旺相｜得日月或動爻生扶 → 任一成立=假空。
  **真空（到底空，凶）**：休囚安靜＋(被日剋｜被動爻剋｜伏而被剋｜靜逢月破)；或季節真空：春土、夏金、秋木、三冬火。
- **依據**：增刪卜易·旬空章（野鶴）；卜筮正宗·旬空論第十。
- **引擎**：**缺**。目前只標「是否旬空」，未區分真/假空。**高優先**：可純干支+旺衰+動靜計算。

### B3. 沖空填實 / 合空無功 / 自空化空
- **條件**：空爻被日辰或動爻沖→沖空則實（轉有用，應於沖實/出旬日）；空爻被合→無功；動爻化空→不作真空；自空化空且無生扶→凶咎。
- **依據**：黃金策「空逢沖而有用，合遭破以無功」「自空化空，必成凶咎；空化空，雖空不空」。
- **引擎**：**缺**。需先有六合六沖判定（見 D）+ 旬空 → 可算。

## C. 月破

### C1. 月破起例
- **條件**：輸入月建(節氣月支) → 破爻＝月建之對沖支（寅破申、卯破酉、辰破戌、巳破亥、午破子、未破丑、申破寅、酉破卯、戌破辰、亥破巳、子破午、丑破未）。純對沖可算。
- **依據**：卜筮正宗·月破起例；增刪卜易·月將章。
- **引擎**：**缺**（核心斷卦層）。注意 `almanac.py` 的「月破」是擇日用日破，與卦爻月破不同，不可混用。**高優先**。

### C2. 真破 vs 假破（動靜分判）
- **條件**：發動之月破爻→仍能生剋（動傷爻、變傷動），待出月/填實/逢合而起；靜而月破＋無日辰動爻生助→真破到底無用。真破加重條件：安靜＋再值旬空＋休囚＋被動爻/月建/日辰剋害。
- **依據**：增刪卜易·月破章（野鶴）；卜筮正宗·月破論。
- **引擎**：**缺**。依賴 C1 + 動靜 + 旺衰 + 生剋，全可算。

### C3. 出月平復 / 逢合 / 填實
- **條件**：換月(月建已過)→不再以破論，恢復本性；逢六合之日不破；值本支(填實)之日不破。
- **依據**：增刪卜易·月破章「出月則不破，逢合之日則不破，實破之日則不破」。
- **引擎**：**缺**（屬應期，見 H）。

## I. 反吟 / 伏吟

### I1. 爻反吟 / 卦反吟
- **條件**：動爻與變爻地支相沖=爻反吟（如巳↔亥）；本卦變卦內外卦俱沖反復=卦反吟（如乾變坤）。主反覆。用神不臨反吟雖反覆終成；用神旺相不變沖剋者雖反復事必成（假反吟）；用神休囚臨反吟=真凶。

- **依據**：增刪卜易·反伏章。
- **引擎**：**缺**。動爻+變爻同支即可判，最易實作。

## 第二部:判讀原則(寫進解卦 prompt)

# 六爻判讀原則（供 AI 解卦 prompt 用）

說明：本表只收「需依卦意人事判斷、語意可彈性詮釋」的判讀型原則，已剔除純干支生剋算法（那些屬程式可定的確定性規則）。每條附原文依據與白話解讀方向。

## 一、用神／原神／忌神／仇神 的關係解讀

### 1. 取用神為斷卦第一步
- 原則：不論占何事，先依占問之人事定何爻為用神，再看其旺衰、有無原神生扶、有無忌神剋害。
- 原文：「不拘占何事，先看何爻為用神。既得用神，須看旺相否？有元神動而生扶否？有忌神動而剋害否？」(增刪卜易)
- 白話方向：先鎖定「這件事的主角是哪一爻」，再看它過得好不好、有沒有貴人幫、有沒有人扯後腿。這是一切解讀的綱領，不可跳過。

### 2. 用神有氣無傷則成，徒存被傷則不遂
- 原則：用神旺相、無刑沖剋害之病，所謀皆成；用神雖出現卻被剋傷，凡事難成。
- 原文：「用神有氣無他故，所作皆成；主象徒存更被傷，凡謀不遂。」(黃金策)
- 白話方向：主角本身強健又沒受傷，事情就順；主角雖在場卻被打壓受剋，再怎麼努力也難成。判吉凶先看「有氣」還是「被傷」。

### 3. 有傷須救、無故勿空
- 原則：用神受傷須有他爻來生扶或制忌神來救；用神若無真實損傷之空亡則不必過慮。
- 原文：「有傷須救，無故勿空。」(黃金策)
- 白話方向：主角受了傷，要看有沒有人來解救（有救則轉吉）；若只是暫時的空、並無實傷，不用過度擔心。

### 4. 仇神發動則禍最重
- 原則：仇神動則原神被傷、用神無根、忌神倍力，其禍最重；斷卦除看用神旺衰，亦須察仇神是否發動。
- 原文：「如卦中仇神發動，則原神被傷，用神無根，忌神倍力，其禍可勝道耶。」(卜筮正宗)
- 白話方向：仇神是四神中最該警惕的惡爻——它一動，等於同時切斷貴人、抽掉主角的根、又替小人加碼。看到仇神發動，凶象要往重裡看。

### 5. 衰空之用神得原神生扶，待時而應
- 原則：用神旬空、月破、衰弱或伏藏，而得原神發動來生者，須待用爻出旬、出破、得令值日，所求方遂。
- 原文：「如用神旬空、月破、衰弱，或伏藏不現，得原神動來生之……必待用爻出旬出破，得令值日，所求必遂矣。」(卜筮正宗)
- 白話方向：主角眼下虛弱或不在場，但有貴人在動著幫他——事情不是不成，而是要「等時候」。可給出「時機未到、待某時段轉機」的語氣。

### 6. 遇凶宜避（演繹，勿當定論）
- 原則：卦遇凶星，避之則吉。
- 原文：「卦遇凶星，避之則吉。」(黃金策)
- 白話方向：遇到凶象，與其硬碰，不如暫避其鋒、待凶氣自散。注意：原文僅泛言遇凶宜避，不要把它窄化成某種固定機械斷法。

## 二、旺衰的人事含意

### 7. 生扶拱合如及時雨、剋害刑沖如秋霜
- 原則：用爻受生扶拱合為吉（旺），受剋害刑沖為凶（衰）。
- 原文：「生扶拱合，時雨滋苗。剋害刑沖，秋霜殺草。」(黃金策)
- 白話方向：有人生我、有同類幫襯、有合來相助，像久旱逢雨，事順人和；被剋、被沖、被刑，像秋霜打草，再好的苗也凋。

### 8. 太過者損之、不及者益之，貴中和
- 原則：過旺須剋洩制方成，過衰須生扶方利；中和為貴。
- 原文：「太過者損之斯成，不及者益之則利。」(黃金策)
- 白話方向：不是越旺越好。太旺要適度收斂（剋洩），太衰要扶持；最理想是中和。解讀「過旺」時可提醒物極必反、需節制。

### 9. 衰得生扶如貧者得貴人提拔；旺靜不如衰動
- 原則：衰弱休囚之爻若得日月動爻生扶拱合，則衰而亦旺、仍可為用；動爻能剋靜爻，衰動之爻可剋旺靜之爻。
- 原文：「衰弱用神得日辰動爻生扶拱合，如貧賤之人而得貴人之提拔。動猶人之起，靜猶人之伏。」(黃金策直解／卜筮正宗注；屬注家白話，非賦文原句)
- 白話方向：弱者遇貴人提拔可翻身；「動」勝過「靜」——主動出擊的弱者，反能壓過按兵不動的強者。鼓勵「採取行動」的語氣可由此出。

### 10. 太歲宜靜不宜動（大事）
- 原則：占國事、官非、大事時太歲最尊，動則影響全局；一般占事太歲力小於月建、日辰。
- 原文：「最惡者歲君，宜靜不宜動。」(黃金策)
- 白話方向：涉及大局／公門／重大事，太歲動是大震盪，多主不安；日常小事則太歲影響有限，須看占類分輕重。

### 11. 先別旺衰動靜，再論吉凶（方法總綱）
- 原則：先確定各爻旺相休囚與動靜狀態，再據以論生剋刑沖合之力量大小與成敗。
- 原文：「別衰旺以明剋合，辨動靜以定刑沖。」(黃金策)
- 白話方向：解卦次序是「先量強弱、再看誰動誰靜，最後才談誰剋誰、誰合誰」。不可顛倒。

### 12. 沖旺爻為暗動、沖衰爻為日破
- 原則：日辰沖旺相安靜之爻為暗動（雖靜實動，仍能生剋）；沖休囚衰弱之爻為日破（沖散無用）。
- 原文：「沖旺相之靜爻，既為暗動；沖衰弱之靜爻為日破。」(增刪卜易)
- 白話方向：同樣被沖，強者被沖反而暗中發力（暗助或暗損，看它生我剋我），弱者被沖就散了。判暗動吉凶須先看它對主角是生是剋。

### 13. 真空假空之辨（衰空才凶）
- 原則：旺不為空、動不為空、有日月動爻生扶者不為空；唯衰絕無扶又逢空者方為真空。
- 原文：「旺不為空，動不為空，有日建動爻生扶者不為空……真空為空。」(增刪卜易)
- 白話方向：不要一見「空」就斷沒戲。只有又弱又沒人幫又落空的，才是真的落空；旺的、動的、有人扶的空，只是暫時不到位，會「出空」後生效。

### 14. 月破不必百無一用，須分動靜
- 原則：發動之月破爻仍能生剋他爻、待時可成；唯靜而不動又無生助者，方到底而破。出月則平復。
- 原文：「動則能傷於爻，變則能傷於動……惟靜而不動，又無日辰動爻生助，實則到底而破矣。」「目下雖破，出月則不破。」(增刪卜易)
- 白話方向：月破不等於全廢。若它在動、或換了月份，破象會緩解、甚至復起；只有又靜又沒援手的破，才是真正的破敗。

### 15. 入墓昏昧，須沖開方顯
- 原則：用爻入墓則昏昧不能為用，須待沖開墓庫方起用；旺相入墓不死、待沖開為應吉之期，休囚入墓方凶。
- 原文：「死墓絕空，乃是泥犁之地。」「墓中人不沖不發。」(黃金策／俗諺)
- 白話方向：入墓像被關進倉庫、暫時出不來、人事昏昧停滯。但若主角本身旺，只是被收著，等「沖開」那天就出頭；若主角本就弱又入墓，才真凶。

### 16. 空、破之最終吉凶須看所占事體
- 原則：同為逢空逢破，求成之事忌空破，求散脫之事（如占官災牢獄、脫貨求散）反喜空破。
- 原文：「月破多以無用推，然不可一概而論。須看用神旺衰，須看遠事近事……豈可謂之有亦如無，毫無所用耶？」(增刪卜易)
- 白話方向：空與破是吉是凶，要看「你想要的是成還是散」。想成的事，空破是阻礙；想擺脫、想散去的事（牢獄、官非、脫手），空破反而是好事。

## 三、墓庫的判讀

### 17. 入墓吉凶不可機械，先看旺衰
- 原則：用神（世爻）旺相有氣者雖隨鬼入墓亦不死；唯休囚無氣又入墓者方見凶危。
- 原文：「亦必休囚無氣，始見凶危；見用神旺者……隨鬼入墓而不死也，化墓不死，動墓亦不死也。」(增刪卜易)
- 白話方向：見墓別急著斷死。主角強健者入墓只是一時受困，旺則無妨；主角虛弱者入墓才是真危。

### 18. 旺相入墓而得生扶，仍有救解
- 原則：用神旺相入墓若再得日月動爻生扶，仍有救解，不作凶斷。
- 原文：「若旺而有扶，仍有救解。」(增刪卜易)
- 白話方向：被困之中又有人來幫，等於困境中有貴人，可往「有驚無險、終得解圍」解。

### 19. 用爻重叠喜墓庫收藏（墓的正用）
- 原則：用神／動爻太多太雜時，反喜墓庫收束歸一，為吉，與「入墓為凶」相反。
- 原文：「用爻重叠，喜墓庫之收藏。」(黃金策)
- 白話方向：力量太散、頭緒太多時，墓庫像個收納櫃，把分散的力量收攏歸一，反而成事。並非所有入墓都凶。

### 20. 論生不論墓
- 原則：五行雖逢墓地，若得沖墓之支沖動，或卦中生爻多而生扶，則論生不論墓。
- 原文：「金爻雖墓於丑土，若得未土沖動，或卦中土多生金，論生不論墓也。」(增刪卜易)
- 白話方向：入墓但同時被沖開、或四周生我的力量很足，就以「得生」為主來解，墓象退居其次。

### 21. 破除「見三墓即斷死」
- 原則：不可一見入墓即斷凶；辰戌丑未日幾乎天天有墓爻發動，斷墓必以旺衰、生扶、沖開為準。
- 原文：「執此數論，若逢辰戌丑未之日，竟不敢占卦矣！」(增刪卜易，覺子)
- 白話方向：墓象很常見，不能逢墓就喊凶。務必結合主角強弱、有無生扶、能否沖開三項綜合判斷。

### 22. 命入兩墓、身入墓爻，主病危／求謀多阻（身命壽元類）
- 原則：本命同入兩墓、或世用隨鬼入墓而休囚，主病危入陰、終身求謀多阻。
- 原文：「命入幽冥兩墓，泉世之人；身入墓爻，到老求謀多戾。」(黃金策，身命／壽元類)
- 白話方向：用於身命、壽元、重病之占，且須配合主角休囚才作此凶斷；非一般小事可套。

## 四、動爻變化的吉凶語意

### 23. 進神向上發展、退神逐步收斂
- 原則：進神由此而進如春木之榮、有源之水，主事勢向上久遠；退神由此漸退如秋木凋零，主逐步收斂。
- 原文：「進神者，由此而前進也，如春木之榮，有源之水……退神者，由此而漸退也，如秋天花木，漸漸凋零。」(增刪卜易)
- 白話方向：進神＝事情有後勁、會持續發展、越來越好（若是吉神）；退神＝勢頭在收、會慢慢淡去。但「進得好不好」要看它是吉神還是忌神——吉神宜進、忌神宜退。

### 24. 真假進退（進不進、退不退）
- 原則：進退能否即時應驗，視旺衰與空破沖合而定；旺相乘勢即進，休囚待時而進，逢空破沖合者待填實合沖之期方進（退神同理）。
- 原文：「吉神宜於化進，忌神宜於化退……旺相者乘勢而進，休囚者待時而進……」(卜筮正宗)
- 白話方向：化進不一定馬上進、化退不一定馬上退。強的當下就進，弱的要等時機，落空破合的要等「填實／逢沖」那天才算數。可用於講應期與「趨勢成立與否」。

### 25. 用神化進為有用、化退為無用
- 原則：用神化進神為有用之用神（吉向），化退神為無用之用神（凶／事退）。
- 原文：「吉神宜於化進，忌神宜於化退。」(卜筮正宗)
- 白話方向：代表事的主角若越走越旺（化進），可看好；若越走越退（化退），事情在縮、在退場。

### 26. 動而化空雖空不空、自空化空則凶
- 原則：空爻化空爻因動不以真空斷「雖空不空」，待出空仍可用；但自空又化空且無生扶，則「自空化空必成凶咎」，須辨旺衰生剋。
- 原文：「用化用，有用無用；空化空，雖空不空。」「自空化空，必成凶咎。」(黃金策)
- 白話方向：兩重落空也未必全廢——若有後援、待出空填實仍可成；但若全無生扶的雙重空，就要往凶斷。關鍵在有無救應。

### 27. 化墓化絕主受困力盡、待沖待生方起
- 原則：化墓主收藏拘束、待沖墓方起；化絕主力盡、待生扶解絕方起，多主凶滯。
- 原文：「入墓難剋，帶旺匪空。……墓中人不沖不發。」(黃金策)
- 白話方向：化墓＝事情被收進櫃裡停滯，要等沖開；化絕＝力氣用盡到谷底，要等生扶來回血。兩者當下都偏滯礙，但都有「待時轉機」的出口。

### 28. 隨官入墓主拘束沉滯纏病
- 原則：用神／世爻隨官鬼入墓、或化墓、日墓動墓，主拘禁、沉滯、纏病；墓中人不沖不發。
- 原文：「入墓難剋，帶旺匪空。……墓中人不沖不發。」(黃金策／增刪卜易)
- 白話方向：用於官訟、牢獄、纏綿之病的占斷，象主被綁住、走不開、拖延；待沖墓之日方解。仍須看主角旺衰定凶之輕重。

### 29. 卦反吟主反覆向下、百事不順
- 原則：本卦變卦內外卦俱沖、反復成另一卦為卦反吟，主反覆、不寧、謀事多悔。
- 原文：「卦變者，內外動而反伏者，同一卦也，如乾卦變坤卦。」(增刪卜易)
- 白話方向：反吟＝來回折騰、一波三折、心神不寧。內卦反吟內部不安、外卦反吟外境不寧。

### 30. 爻反吟主反覆；旺則終成、衰則真凶
- 原則：用神不臨反吟雖反覆終可成；用神臨反吟則謀事主凶。（須辨真假反吟）
- 原文（可考章句）：「反伏卦，用神旺相不變沖剋者，雖則反復，事之必成。」(增刪卜易)
- 白話方向：事情會反覆來回。若主角夠旺，折騰到最後仍能成（假反吟）；若主角弱又臨反吟，才是真折損。

### 31. 伏吟主憂鬱呻吟、停滯徘徊
- 原則：伏吟之象主憂鬱呻吟、進退不得、原地徘徊；內卦伏吟內憂、外卦伏吟外不寧；吉凶仍看用神旺衰。
- 原文：「反伏者，有內外伏吟者，內外憂鬱呻吟之象。內卦動變伏吟，內則呻吟；外卦動變伏吟，外則憂鬱。」(增刪卜易)
- 白話方向：伏吟＝有苦難言、卡住動彈不得、原地打轉。語氣偏「停滯、鬱悶、想動動不了」，最終吉凶仍要回到主角強弱。

### 32. 真假反吟伏吟之辨（不可一概畏懼）
- 原則：用神得日月生扶旺相而臨反伏者，反覆中仍能成事（假）；用神休囚無氣又臨反伏者方真凶。
- 原文：「反伏卦，用神旺相不變沖剋者，雖則反復，事之必成。」(增刪卜易)
- 白話方向：見反吟伏吟別一律喊凶。主角強，折騰歸折騰、終究成；主角弱，才是真凶。

### 33. 動逢沖則事散、空動逢沖則沖實有用
- 原則：發動不空之爻逢沖為沖散（事散，凶）；發動旬空之爻逢沖為沖實沖起（反而有用，吉）。
- 原文：「動值合而絆住，靜得沖而暗興；動逢沖而事散。」(黃金策)
- 白話方向：同樣逢沖，要看那爻空不空。實實在在動著的被沖＝事情中途散掉；空著動的被沖＝反而被「填實」激活，轉為有用。

### 34. 動值合而絆住、忌爻喜爻合住相反斷
- 原則：動爻逢合則絆住不能動；所忌之爻合住則不成凶（吉），所喜之爻合住則不濟事（凶）。
- 原文：「動值合而絆住。……所忌之爻動而合住，則不成凶；所喜之爻動而合住，則不濟事。」(黃金策)
- 白話方向：合會把動的爻「黏住」不動。若黏住的是壞爻（忌神），反而好（壞事發不起來）；若黏住的是好爻（喜神），就壞了（好事使不上力）。

### 35. 絕處逢生，凶中有救、事終可成
- 原則：用神臨絕地而得動爻或日月回頭生扶，謂絕處逢生，凶中有救，事終可成。
- 原文：「絕逢生而事成……用神臨於絕地，倘遇生扶，乃凶中有救。」(黃金策)
- 白話方向：主角看似走到絕地，卻有生扶救援＝絕處逢生，可往「谷底反彈、絕境逢貴人」解，凶象轉吉。

### 36. 合處逢沖，事必臨成見散
- 原則：成事得合卻被日辰／動爻沖破其合，謂合處逢沖，事必臨成見散；反之欲散之事得之則遂意。
- 原文：「合遭破以無功。……凡遇成事而得合處逢沖之卦者，事必臨成見散。」(黃金策／卜筮正宗直解)
- 白話方向：眼看要成、卻在臨門一腳被沖散——多因中途生變、有人從中作梗。但若你本就想散、想脫身，這反而是好兆。

### 37. 凶化長生熾而未散、吉連沐浴敗而不成
- 原則：凶神動化長生，其凶綿延未散（應期拖長）；吉神動化沐浴（敗地），則吉象敗而不成。
- 原文：「凶化長生，熾而未散；吉連沐浴，敗而不成。」(黃金策)
- 白話方向：壞事若化長生，凶氣會延綿不退、難了結；好事若化沐浴（敗地），則好景半途敗壞、終難成。

## 五、合沖刑的人事語意

### 38. 凡得諸合，諸占多吉（須用神有氣）
- 原則：得合則占名成、占婚成、占宅旺、占求謀遂心；但前提須用神有氣相宜，用神失陷則合無益。
- 原文：「凡得諸合，諸占皆以為吉……然必用神有氣相宜，用若失陷無益。」(增刪卜易)
- 白話方向：合主和合順遂、人事相投、事情湊得攏；但要主角本身夠力才作數，主角太弱，合也白合。

### 39. 六沖卦變六合卦，先難後易、終成
- 原則：不論用神旺衰，徑以吉斷，主散而復聚、離而必合：占婚先離後成、求謀先難後易、家宅先衰後盛。
- 原文：「獨此六沖卦變六合得不看用神，竟以吉斷……占婚姻先吳越而後朱陳……占家宅先衰後盛。」(增刪卜易)
- 白話方向：開頭波折、結局圓滿的典型卦象。可給「先苦後甜、由散轉聚、終必成合」的明確正面語氣。這是少數可不看主角強弱即斷吉者。

### 40. 六合卦變六沖卦，先成後敗、得而復失
- 原則：用神旺者始吉終凶、有始無終，主先合後離、得而復失；惟占官非、盜賊宜之（喜其終散）。
- 原文：「凡得六合變六沖者，諸占先合後離……得而復失，成而後敗，惟占官非、盜賊事者宜之。」(增刪卜易)
- 白話方向：開頭好、後來散的典型。提醒「眼下雖好，恐難長久、慎防後變」。但若占的是官非、盜賊要它散，反為吉。

### 41. 六合卦變六合卦，始終作合、長久堅固（宜合吉不宜合凶）
- 原則：主始終作合、長久；喜慶事吉；但占訟獄、憂疑、占產則反凶（不宜合凶）。
- 原文：「動而變六合謂始終而作合也……宜合吉，不宜合凶……惟占訟獄不利……占產難生。」(增刪卜易)
- 白話方向：婚姻、事業、財帛之占主長久穩固、白頭基業；但訟獄、憂疑、生產之占則「黏住解不開」反成糾纏難解。看事體定吉凶。

### 42. 沖者散也：凶事宜沖、吉事忌沖
- 原則：占凶事宜沖散（吉），占吉事逢沖（凶）；用神旺則雖沖不破，用神失陷則凶而又凶。
- 原文：「沖者散也，凡占凶事宜於沖散、占吉事而不宜……用神旺雖沖不破，用神失陷凶而又凶。」(增刪卜易)
- 白話方向：沖＝打散、解開。想散的（病、災、官非）逢沖是好事；想成的（婚、財、功名）逢沖是壞事。但主角夠旺時，沖不散它。

### 43. 沖中逢合，沖不為害反吉
- 原則：用神被沖而得日辰來合者，沖中逢合，沖不為害反吉。
- 原文：「世爻酉金化卯相沖……幸辰日合之，沖中逢合……卻有財利。」(增刪卜易)
- 白話方向：本來被沖（要散、要壞），半路殺出個「合」把它拉住，化解了沖——往「先有驚、後逢解、終有得」解。與「合處逢沖」恰好相反。

### 44. 用神被三合局合住，主羈絆留滯
- 原則：占出行／行人，用神在三合局內被合，則被合而留、被合不回。
- 原文：「占出行用神在三合內被合而留。占行人用神在三合之內被合不回。」(增刪卜易)
- 白話方向：合在這裡是「被綁住、走不開」——出行的人被事絆住、外出的人一時不歸。與合主和合的吉意不同，須看用神是被合「相助」還是被合「絆住」。

### 45. 暗動主私下之事：生我暗助、剋我暗損
- 原則：暗動之爻生扶我，得私下一人幫襯（吉）；剋害我，被一人在私下謀損（凶）。
- 原文：「暗動之爻生扶我，定叨私下一人幫襯；倘或剋害我，定被一人在私下謀損。」(卜筮正宗直解)
- 白話方向：暗動＝檯面下、看不見的力量。生我＝暗中有貴人相助；剋我＝暗中有人下絆子、扯後腿。可解出「私下、暗裡、不明說」的人事。

### 46. 刑合剋合，終見乖淫、不和
- 原則：合中帶刑、帶剋者，合而有剋畢竟不和、合而有刑終成乖戾；占妻妾多不正、占財為不正之財。
- 原文：「刑合剋合，終見乖淫……占妻妾多不正，占財亦是不正之財也。」(黃金策)
- 白話方向：看似合好，內裡卻夾刑帶剋——表面親近、實則不和諧、不乾淨。可解「貌合神離、來路不正、藕斷絲連有瑕」。

### 47. 貪生貪合，刑沖剋害皆忘
- 原則：刑沖剋害之凶神，若旁有生爻合爻，則凶神貪生貪合而不為患（貪合忘刑、貪生忘沖）。
- 原文：「貪生貪合，刑沖剋害皆忘。」(黃金策)
- 白話方向：壞爻本要來剋來沖，但旁邊有更吸引它的「生」或「合」，它就顧著去貪那邊、忘了害你——凶被「岔開」化解。可解「危機被別的事牽走、無暇加害」。

### 48. 成家忌六沖、創業喜六合
- 原則：占成家立業，六沖之卦不利（根基難守），六合之爻為喜（易成創立）。
- 原文：「若問成家，嫌六沖之為卦；要知創業，喜六合之成爻。」(黃金策)
- 白話方向：要扎根、守成、安家的事，怕沖（散、難守）；要創立、結盟、湊合的事，喜合（聚、易成）。

### 49. 三刑不可單斷凶，須用神休囚兼他爻犯之
- 原則：三刑須在用神休囚又兼他爻犯之時方見凶；單犯三刑得驗者極少，不可單以三刑斷凶。
- 原文：「夫三刑者，予屢試之，或因用神休囚又兼他爻犯之，刑者則見凶，而獨犯三刑得驗者少。」(增刪卜易)
- 白話方向：別一見三刑就喊凶。只有在主角本就虛弱、又同時受其他傷害時，三刑才應凶；單獨一個三刑，多半無妨。

## 六、飛伏（用神不上卦）的白話

### 50. 用神不現以伏神補救，但野鶴主張不現可再占
- 原則：用神不上卦則查伏神；但野鶴認為用神空破衰絕者禍福已知八九，不必拘泥繁瑣伏神推演，不如再占一卦合而決之。
- 原文：「野鶴曰：何必如此？用神空破衰絕，禍福已知八九，何不再占一卦，合而決之。」(增刪卜易)
- 白話方向：主角沒出現（伏藏）時，可看它伏在誰底下；但若主角又空又破又衰，其實已大致定論，不必硬鑽伏神，重占一卦合參更穩。

### 51. 飛伏關係：飛生伏吉、飛剋伏凶、伏生飛洩氣、伏剋飛可出
- 原則：飛來生伏為吉（得長生）；飛來剋伏為凶（反傷身、難出）；伏去生飛為洩氣（半凶）；伏剋飛則伏能破飛而出（出暴，主可出）。
- 原文：「伏剋飛神為出暴，飛來剋伏反傷身，伏去生飛名洩氣，飛來生伏得長生。」(卜筮正宗)
- 白話方向：伏神＝藏著的主角，飛神＝壓在它上面那爻。上面的扶它（飛生伏）＝有人撐它出頭；上面壓它（飛剋伏）＝被壓著出不來；它反過來頂開上面（伏剋飛）＝衝得出來、藏不住。

### 52. 伏無提拔終徒爾、飛不推開亦枉然
- 原則：伏神若無生扶提拔終徒勞；飛神若無沖開，伏神亦難顯。提拔與推開二者缺一不可。
- 原文：「伏無提拔終徒爾，飛不推開亦枉然。」(黃金策)
- 白話方向：藏著的主角要出頭，須兼具兩件事——有人拉它一把（生扶提拔）、上面那層被推開（沖飛）。少一樣都難現身。

### 53. 空下伏神易出、制中弱主難維持
- 原則：伏神居於旬空之飛爻下，因飛空無阻易被引拔而出（吉）；用神衰弱又遭月日制剋者，縱有生扶亦難維持（凶）。
- 原文：「空下伏神，易於引拔；制中弱主，難以維持。」(黃金策)
- 白話方向：壓在它上面那層若是空的（沒擋著），藏著的主角容易冒出來；反之主角本就弱、又被月日壓制，就算有人幫也撐不住。

### 54. 失物盜賊占：伏剋飛物被他人藏匿、飛剋伏為我所獲
- 原則：占失物盜賊，伏神剋飛神則物終被他人隱匿；飛神剋伏神則為我方所擒拿。
- 原文：「伏若剋飛，終被他人隱匿；飛如剋伏，還為我輩擒拿。」(黃金策)
- 白話方向：專用於尋物、捉賊。注意此處剋向之解（落誰手）與「伏剋飛＝可出」的吉凶取向是兩回事——一論能否現身、一論物落誰手，須分清語境。

# 各占類取用神與斷法總表

> 來源典籍簡稱:**增** = 增刪卜易(野鶴老人)、**黃** = 黃金策(劉伯溫)、**正** = 卜筮正宗。✅=§5.1 已涵蓋、⚠️=部分涵蓋/不精確、❌=缺。

## 一、占婚姻 / 姻緣 / 夫妻

**① 取用神**
- 男占妻 / 男代占女 → **妻財**;女占夫 / 女代占男 → **官鬼**。
- **世爻**=自己;**應爻**:增刪卜易主「應為對方身/家」,黃金策主「世為男家、應為女家」(兩說並存,以增刪為主)。
- 增刪駁黃金策「以應為用神」之說:**以財官為重、世應為輕**。

**② 原神 / 忌神**
- 男占(用財):原神=子孫;**忌神=兄弟**(克財傷妻、阻隔)。
- 女占(用官):原神=妻財;**忌神=子孫**(克官傷夫,主再嫁)。

**③ 關鍵斷法**
1. 取用總則:「男家占女…無不以財為用。女家占男,皆以官為用。用官者,官有生扶;用財者,財爻旺相,即許婚。」(增·婚姻章)
2. 用神生合世最吉:「財爻應爻同來生合世爻者更吉,大抵以財爻為重,他爻為附和耳。」(增,駁黃金策「重應」)
3. 男占兄動為凶:「兄爻持世或兄動,乃傷妻阻隔之神,此婚必難成」;**但**「得財爻動來相合,此婚必成」(增)。
4. 女占官持世吉、子孫動凶:「官星持世合世生世旺相者…姻緣必就」「子孫乃傷夫之神,未成者不成,已成者傷夫再嫁」(增)。

   - **「行人占化進神=不歸」是反例**(一般化進神為吉/進益),引擎已偵測進退神,須標明此占類例外。

### B. 中優先(補一個「占類專屬定位/反例」速查表)

6. **訟事核心斷**:「**世宜旺、應宜衰(世旺應衰我勝);子孫=解神(動或持世主和解/訟散);鬼剋世/應剋世=成訟、受屈**」。

7. **逃亡/尋人方向**:「**世剋應=可尋獲、應剋世=難尋**」(引擎已有世應生剋)。

8. **求財原神/動向**:類象表「妻財」補「**子孫為財之元神(生財源,子孫旺則財源厚)**」;另補「**財生合持剋世=財來就我易得、財與世無涉=我去尋財難得**」(引擎已有用神對世關係)。

### C. 低優先 / 引擎缺能力,暫以註記方式處理

9. **天時六親分主**(父雨/財晴/子孫大晴/官鬼雷電/兄弟風)——若不接天氣占可暫緩,僅在類象表加註。

10. **胎產四事分占 + 胎爻**:引擎**目前無胎爻概念**,「有孕無孕專取胎爻」無法支撐;建議先在 prompt 註明「**胎產類宜一事一占,有孕無孕之占本系統暫不支援(無胎爻)**」,避免硬判。同理「子占母孕→兄弟」可一句帶過。

11. **家宅/墳塋野鶴「一念一事一卦分占」**:作為通則註記補入——「**家宅、墳塋類忌一卦斷全家,宜分項各占,取該事六親為用**」,呼應野鶴駁古法。

### D. 配合任務開頭所列「尚未處理」的引擎缺口,優先級對應

- **墓庫(隨鬼入墓/入墓)**:婚姻「破墓絕空」、疾病「隨鬼入墓主凶」、蓋造「最忌隨官入墓」、求財「財入墓待沖開」皆高頻用到 → **隨官入墓**建議優先補偵測。
- **進神/退神**:行人占(化進不返/化退必歸)、婚姻(化進事成/化退難就)依賴此,且**行人為反例** → 補進退神偵測後須同步在 prompt 標占類差異。
- **月破**:疾病(久病月破凶)、各占用神月破皆需 → 補月破標記。
- **應期(沖空/開墓/三合沖開/逢值)**:行人歸期、求財得財之日、產期、失物尋回皆靠此 → 應期推算補齊後可大幅提升「五段·應期」實用性。
